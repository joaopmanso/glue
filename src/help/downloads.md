Download works for the songs on this computer, and for the ones on your other computers, as long as GLUE Home is running on the computer that has them.

## What to download
- **One song:** right-click it › **Download**. You get its file.
- **Several songs:** select them, right-click › **Download N songs as a zip**.
- **A playlist:** right-click it in the sidebar › **Download as a zip**. Its songs go in a folder, numbered in the playlist's order (`01 …`, `02 …`), so the set stays in order on a USB drive.
- **A folder of playlists:** the same, with each playlist in its own folder inside.
- **A DJ app's playlist,** or a **Discogs playlist's** digital songs: the same, from its menu.

## For a USB drive
1. Download the playlist and save the zip on your computer.
2. Unzip it, and copy the folder onto the drive.

## While it downloads
- **Keep the tab open.** The panel shows how far it is, and **Cancel** stops it.
- **If the connection drops,** GLUE tries again and carries on from where it was.
- **A song that can't be fetched** is left out, and the rest still come. The panel lists what's missing and why, so check it before a gig. Songs with no file linked are listed too.
- **Chrome and Edge** save straight to disk, so any size fits. **Other browsers and phones** gather the songs first, which needs room in the browser: download smaller sets there.
