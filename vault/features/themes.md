# Themes

## What it does
Choose how MCO looks: a theme (colours, fonts, shape) and dark, light or match-the-system mode.

## Behaviour
- "Who's using MCO?" › Appearance: four themes with live previews (Classic, Studio, Riso, Moss) and a
  Dark / Light / Match system switch. The header's sun/moon button flips dark and light anywhere.
- Remembered in the browser and in the MCO folder ([ADR 0028](../adr/0028-themes.md)).

## Open
- The user tries Studio, Riso and Moss and picks the new default.
