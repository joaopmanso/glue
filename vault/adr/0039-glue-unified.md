# 0039. GLUE stands for Global Library Unified Exporter

## Context
[ADR 0035](0035-rename-to-glue.md) spelled GLUE out as "Global Library Utility Exporter". The user
corrected it the same day: the U is **Unified**.

## Decision
GLUE = **Global Library Unified Exporter**, everywhere the name is spelled out (header, title,
description, docs, the /mco/ redirect page). Everything else in ADR 0035 stands.

## Consequences
- None beyond the wording.
