# Handoff, 2026-09-27: the user's list (11 bugs, 8 features) before ASIO

If the session ends midway, carry on from here. Work happens on `home-engine` and is fast-forwarded to
`main`. The full plan was approved by the user (a Claude plan file, summarised below).

## Standing rules from the user
- Deploy after validation: fast-forward `main` and push; a `home-v*` tag only when `home/` changes.
- Keep the vault current in the same commit.
- The user hand-tests each batch.

## Decisions taken with the user
- **Tag edits** go into the files through GLUE Home (Rust `lofty`). Without it they're kept in GLUE,
  marked "not in the file yet", and written once it runs.
- **Event reminders:** a banner in GLUE, and desktop notifications from GLUE Home.
- **DJ-app icons:** GLUE's own badges in each app's colours (done: `ui/AppIcon.svelte`).

## Done and deployed
- **Batch 0:** the page froze below ~850 px wide (the narrow layout lost its height, and the table drew
  every row).
- **Batch 1:** the fixed selection bar, "+N more" on Details, the pairing code's Copy, Back to the
  library and the logo, Prepare by default, reordering Next from and clearing Played before, the
  sidebar folding (Ctrl+B), the app badges.
- **Batch 2:** duplicates at once (kept result, fingerprint packs, incremental match), column widths
  (drag and fit), the Overview as a waveform.
- **Batch 3:** the quality false positives
  ([ADR 0069](../adr/0069-content-beyond-a-wall.md)). The WAV is now a caution. The MP3 really is
  192 kbps cut at 17 kHz, so its verdict stays, with its specks explained.

  5174 had been serving old code to the tests.
