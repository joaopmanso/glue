### Things learned today (save the next session some time)
- **Global class names in `src/styles/app.css` leak into components:**
  - `.bar` is a 3-px progress bar with `overflow: hidden`;
  - `.top` is the page header;
  - `.row` is used under `.status`.
  - A component using those names picks up their rules; it squashed Browse's find field for a day.
- **Editing files from the shell on Windows:**
  - Don't use `perl -pe 's|…|…|'` when the pattern contains `\|`: the escaped delimiter becomes
    regex alternation and garbles the file.
  - `node -e`/heredocs mangle backslashes and `\n`.
  - For multi-line or backslash-heavy edits, use the Edit tool, or write a small `.cjs` script to the
    scratchpad with the Write tool (`String.raw` for strings with backslashes) and run it.
  - A stray `cat > /dev/null` in a command waits for input forever.
- **Playwright:**
  - The test servers are built once when the run starts, so `src/` and `home/ui/` can be edited
    during a run; `e2e/*.spec.ts` can't.
  - In the phone layout a tab keeps its stack of screens: tap a tab twice to reach its first screen.
  - The Windows clipboard gives `\r\n`.
- **Menus built inside an `$effect`** must be built `untrack`ed (`ui/phone/ActionSheet.svelte`, as in
  `ui/ContextMenu.svelte`). Otherwise every library change (an analysis landing) rebuilds the menu
  under the user's finger.
- **Tauri (GLUE Home):**
  - A plain `#[tauri::command] fn` runs on the main thread (windows and tray); use `async fn` for
    anything that touches files.
  - The crate has no `serde` derive; build JSON with `serde_json::json!`.
  - The npm and crate versions of Tauri packages must match (see `features/deployment.md`).
- **The user's real GLUE Home runs on the desktop (JMansoPC):**
  - e2e tests never use it; the account test blocks `127.0.0.1:47400–47409`;
  - don't stop or restart it;
  - its cache is `%LOCALAPPDATA%\io.github.joaopmanso.gluehome\library` (read only).
