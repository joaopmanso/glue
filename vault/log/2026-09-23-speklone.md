# How Speklone was built (2026-09-23 → 24)

A condensed record of the first sessions, so later work knows what was tried and why.

1. **First version**: single `index.html` Spek-style analyzer; own container parsers; bit-exact
   WAV/AIFF reading; spectrogram, average spectrum, verdict. Published as a claude.ai artifact too.
2. **AIFF bug**: chunk size read from the ID bytes (`getUint32(p)` instead of `p + 4`) → no AIFF ever
   parsed, and error text rewrote any message containing "null" as "couldn't decode". Fixed both.
3. **False "band-limited"** on a genuine 48 kHz Bandcamp AIFF: fade threshold lowered from floor
   + 15 dB to + 6 dB.
4. **MP4s read the video track**: parser took the first `stsd` (avc1). Now follows only the sound
   track; video-only files get a clear message. Unknown-format verdicts no longer say "Genuine
   lossless".
5. **Player** added; AIFF rewrapped as WAV for playback (bit-identical). **Pause bug**: the icon was
   rebuilt every frame, swallowing clicks. Fixed by swapping only on state change.
6. **Live view** added (AnalyserNode at the file's rate, wall-clock scrolling).
7. **Layout**: sidebar with verdict and readouts, window-height-based canvases so everything fits on
   a 1080p screen.
8. **Start page** with a prominent drop zone; example track on demand.
9. **Tempo & key**: first key version landed a fifth off (overtones, kick sweeps); fixed with
   tonal-peak-only, square-root chroma. Camelot / Open Key / Musical notation and wheel.
10. **Stems**: HT-Demucs ONNX. Browser CPU runs out of memory; the model uses float64 in its iSTFT
    (patched to float32 in JS, verified). Tried a local native server (3.6× faster), then removed it:
    the user wants everything client-side for a deployable website.
11. **Deployed** to GitHub Pages under the joaopmanso account.
12. **Mishap**: a test cleanup force-closed all Edge processes on the machine, including the user's
    own windows. Since then only test browsers are closed, matched by their profile path.
